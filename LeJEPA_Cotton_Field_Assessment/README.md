# LeJEPA_Cotton_Field_Assessment

[![PyPI version](https://img.shields.io/pypi/v/LeJEPA_Cotton_Field_Assessment.svg)](https://pypi.org/project/LeJEPA_Cotton_Field_Assessment/)
[![PyPI downloads](https://static.pepy.tech/badge/LeJEPA_Cotton_Field_Assessment/month)](https://pepy.tech/projects/LeJEPA_Cotton_Field_Assessment)

This package contains code for the pretraining and evaluation of a YOLOV8 for two prediction tasks, namely cotton boll detection and plot status classification.

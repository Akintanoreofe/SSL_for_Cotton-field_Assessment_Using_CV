# Installation

## Stable release

To install LeJEPA_Cotton_Field_Assessment, run this command in your terminal:

```sh
uv add LeJEPA_Cotton_Field_Assessment
```

Or if you prefer to use `pip`:

```sh
pip install LeJEPA_Cotton_Field_Assessment
```

## From source

The source files for LeJEPA_Cotton_Field_Assessment can be downloaded from the [Github repo](https://github.com/Akintanoreofe/LeJEPA_Cotton_Field_Assessment).

You can either clone the public repository:

```sh
git clone https://github.com/Akintanoreofe/LeJEPA_Cotton_Field_Assessment
```

Or download the [tarball](https://github.com/Akintanoreofe/LeJEPA_Cotton_Field_Assessment/tarball/main):

```sh
curl -OJL https://github.com/Akintanoreofe/LeJEPA_Cotton_Field_Assessment/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd LeJEPA_Cotton_Field_Assessment
uv sync
```
